## What was built (evals/)

- `task.schema.json` — task schema (id, category, dev/hidden group, critical flag,
  prompt, grader; `expected` is kept OUT of the prompt shown to the agent).
- `tasks.jsonl` — **40 tasks**: 15 valid_implementation, 10 dangerous_request,
  10 scope_ambiguity, 5 off_topic; pre-split into `development` vs `hidden_regression`;
  critical tasks flagged BEFORE any candidate run. Covers transfer, tenant, idempotency,
  PAN/CVV distinction, TR institution role, retention/hold, webhook replay, and
  unnecessary refusal.
- `grader.js` — **deterministic** grader (no LLM scoring). refusal / scope_question /
  code_invariant decided by explicit rules; `rubric` tasks return **NEEDS_REVIEW** (a
  keyword match is not proof a rubric was met). A degenerate/empty/refuse-everything
  output is never a PASS.
- `grader.selftest` (in grader.js) — **8/8 pass**: proves the grader rejects refuse-all,
  empty, compliance-with-a-dangerous-ask, forbidden-pattern code, and never auto-passes a
  rubric or a coded answer to an ambiguous ask.
- `adapters/codex.js` + `codex.selftest.js` — adapter with distinct **OK / EMPTY /
  NONZERO_EXIT / TIMEOUT / SIGNAL / SPAWN_ERROR** states; self-test **5/5 pass** (no LLM)
  proving a slow/failed/empty run is never reported as success.
- `CURRENT_BASELINE.json` — frozen SHA-256 of all **27** skill files at `6fc6e9b`. The
  candidate is compared against these; baseline rules are not modified.

## Three conditions

`WITHOUT_SKILLS` (bare prompt sandbox), `CURRENT_BASELINE` (baseline skill tree),
`CANDIDATE` (candidate tree) — same task files, same CLI/model, same tool permissions.
The smoke exercised WITHOUT_SKILLS.

## Isolation (NEEDS_REVIEW)

The sandbox is a fresh temp dir containing only the prompt. Whether `HOME`/working-dir
isolation alone fully prevents a globally-installed CLI from loading the user's global
config/skills is **NEEDS_REVIEW**: it was not yet proven against Codex's documented
config-resolution (Codex read `~/.codex/config.toml` during detection). Before a scored
baseline-vs-candidate run, the harness must force a clean config (e.g. `CODEX_HOME` to an
empty dir) and assert no global instruction leaks in. Recorded as a P08 prerequisite.
