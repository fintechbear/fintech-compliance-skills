# P07 — CLI diagnostics (install self-check)

**Status: PASS** (validated commit `dbb52c8`, CI success).

P07 ships a small, zero-dependency diagnostic a developer runs to self-check an install.
It reuses the installer's own discovery (`installer/index.js`) so its notion of "current"
can never drift from what the installer writes.

## What was added

- **`installer/diagnose.js`** (zero runtime deps, Node built-ins). CLI:
  `node installer/diagnose.js [--home <dir>] [--target <dir>] [--json]`. Also exposed as the
  `fintech-compliance-skills-doctor` bin and the `npm run diagnose` script; added to the
  published `files` list.
- **`installer/test-diagnose.js`** — cross-platform smoke test (9 assertions).
- **CI wiring** in `.github/workflows/verify.yml`:
  - `control-catalog` job: a source-side self-check step (FCS ids resolve, no legacy citations).
  - `installer` matrix (ubuntu+windows × node 18/20/22/24): a `test-diagnose.js` smoke step.
- **README** "Check your install (doctor)" section, with the consistent **"not a runtime
  compliance audit, not a scanner"** framing.

## What it checks

1. **Which targets are installed** under `--home`/`--target`: claude (user), kiro (home),
   kiro-crew, codex (managed AGENTS.md block).
2. **Per-skill status** via the installer's own `classify()`: `current` / `ours-stale`
   (our stamp but source is newer → re-run the installer) / `user` (you edited it; preserved)
   / `legacy` (old format; migrate) / `absent`.
3. **Source: every FCS-id a skill cites resolves** to `controls/catalog.json`.
4. **Source: no legacy numbered refusal-rule citation** has crept back (the one worked
   example in `refusal/refusal-policy.md` is excluded, exactly as `validate-controls.js` does).

**Exit code:** non-zero on a source defect (unresolved id / legacy citation) or a drifted
(`ours-stale`) install. A target simply **not installed** is reported, not an error.

## Real test results

- `node installer/test-diagnose.js` → **9/9 checks pass** locally (clean install all current
  exit 0; injected `ours-stale` drift detected, exit non-zero; empty home → every target
  not-installed, exit 0).
- **CI (`dbb52c8`): success** — control-catalog (incl. source diagnose) + installer
  18/20/22/24 × ubuntu/windows (diagnose smoke on every leg) + dotnet-postgres-harness.
- Local gate unchanged: validate-controls 23 controls / 33 skills / 0 errors; installer
  verify all pass; installer 27/27.

## Honest limits
- This is a **static integrity check of installed files**, not a runtime compliance audit
  and **not a scanner**. It verifies the skills are present, current, and internally
  consistent; it never certifies that the developer's own code is compliant. The reminder
  line is printed on every run and stated in the README.
- It classifies drift and missing installs; it does not auto-repair (that is the installer's
  job — the diagnostic points you at it).
